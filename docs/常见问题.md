# 常见问题 FAQ

## Q1：页面点「生成」没反应？
**先确认打开方式**：必须在浏览器地址栏输入 `http://127.0.0.1:8190`，**不能直接双击 HTML 文件**（file:// 方式连不上服务，页面会弹全屏提示）。
然后确认服务在运行：双击 `启动闪电生图台.command`。若状态灯显示「服务离线」，先启动服务。

## Q2：提示「队列已满」？
同时最多 3 个任务。等待当前任务完成，或在 ComfyUI 原版界面手动中断任务。

## Q3：提示「翻译服务不可用」？
翻译走 MyMemory 免费接口，断网或超时会**自动降级按原文提交**，不影响出图——只是中文原文对英文模型效果差些。也可在设置中心关闭自动翻译。

## Q4：生成很慢 / 电脑卡？
- 16GB 及以下内存的机器安装器已自动启用低显存参数，请勿去掉
- 关闭其他大内存应用（浏览器多标签页很占内存）
- 用 Turbo 模式 + 小尺寸起步

## Q5：出图和描述不符？
Turbo/SDXL 只懂英文。确认页面右上角状态：中文提示词应显示过「已自动翻译为英文」。若翻译被关闭或降级了，打开设置中心的「自动翻译」。

## Q6：端口被占用？
安装器和服务启动时会自动检测 8188/8190。若提示占用，通常是服务已在运行——直接浏览器打开 `http://127.0.0.1:8190` 即可；确认没有旧进程时执行：
```bash
pkill -f 生图服务器.py
pkill -f "main.py --listen"
```

## Q7：模型下载失败？
安装器会自动在多个源之间回退。全部失败时（网络受限），可手动从 ModelScope 下载对应文件放进 `ComfyUI/models/checkpoints/` 或 `upscale_models/`，重新运行安装器会自动识别到。

## Q8：怎么彻底卸载？
见《安装指南》第五节：停止服务 → 删除安装目录。ComfyUI 本体和模型不受影响。

## Q9：数据安全吗？
完全本地：图像只存在本机 `ComfyUI/output/`，程序不上传任何数据；唯一外部请求是提示词的匿名翻译（可关闭）。详见 [SECURITY.md](../SECURITY.md)。

## Q10：支持 Windows 吗？
当前版本面向 macOS / Linux。Windows 支持在计划中，欢迎提交 PR。
