# 使用教程

## 一、三步出图

1. 双击 `启动闪电生图台.command`，浏览器自动打开 `http://127.0.0.1:8190`
2. 在「画面」区输入描述（中文直接写），点「生成」
3. 等待出图（Turbo 模式 5–60 秒），点击图片可放大，点「保存全部原图到本地」下载

## 二、界面导览

### 模型区
三个模型按钮：**Turbo**（极速，推荐）/ **SDXL**（高清）/ **Z-Image**（中文原生，极慢）。切换后默认参数自动跟随。本机没装的模型会自动置灰。

### 画面区
- **提示词**：越具体越好。中文会自动翻译成英文提交（Turbo/SDXL 需要；可在设置中关闭）
- **负向词**：不希望出现的内容，CFG > 1 时生效

### 参数区（全部可调）
| 参数 | 说明 | 推荐值 |
|------|------|--------|
| 尺寸 | 预设或自定义宽高 | Turbo 768×512，SDXL 1024×1024 |
| 步数 | 采样步数 | Turbo 4 / SDXL 25 |
| CFG | 提示词强度 | Turbo 1.0 / SDXL 7.0 |
| 一次张数 | 批量生成 | 1 |
| 采样器/调度器 | 高级选项 | 保持默认即可 |
| 种子 | 0=随机；固定种子+相同参数=完全复现 | — |
| 超分 ×4 | 追加 RealESRGAN 放大，出 4K 壁纸必备 | 需要高清时勾选 |

### 系统信息卡
右侧自动展示：ComfyUI 版本、PyTorch、显卡/内存、**可用模型清单**、**已装插件**、当前队列状态——打开页面即自动识别，无需配置。

### 设置中心（右上角 ⚙）
语言（中/EN）、主题（亮/暗/跟随系统）、自动翻译、默认模型、默认超分、历史记录条数、恢复默认。全部自动保存在本机浏览器。

### 其他
- 顶栏「ComfyUI 原版界面」：新标签页打开原版工作流面板，节点、连线、全部参数可看可控
- 顶栏 EN/中文：语言切换
- 右上角太阳/月亮：主题切换

## 三、出图历史

面板下方「出图历史」自动记录最近的生成结果（条数在设置中心调整），点击可放大。历史仅保存在本机浏览器。

## 四、实用技巧

- **做桌面壁纸**：Turbo 模式 768×512 + 勾选超分 ×4 → 3072×2048
- **精确复现**：记下出图后的参数行（种子/步数/CFG/采样器/尺寸），下次填入同样数值
- **离线可用**：断网时翻译自动降级（按原文提交），生图功能完全不受影响
- **队列保护**：同时最多 3 个任务，超出会提示稍候，防止低配机器被拖垮
