# 安装指南

本文档对应 **闪电生图台 v4.0**。整个安装过程全自动识别，只需按提示按 Y/N。

## 一、获取源码

```bash
git clone https://github.com/<你的用户名>/lightning-image-studio.git
cd lightning-image-studio
```

无法访问 GitHub 时可下载仓库 zip 解压使用，效果相同。

## 二、运行安装器

```bash
python3 install.py
```

macOS 也可以直接双击仓库内的 `安装闪电生图台.command`（如遇"无法验证开发者"，右键 → 打开）。

安装器将依次执行：

### 1. 许可确认
阅读 MIT 许可与隐私说明，输入 `Y` 继续。

### 2. 环境检测
自动检测系统、架构、Python 版本、磁盘空间、内存。有任何不达标项会明确提示，可自行决定是否继续。

### 3. 检测 ComfyUI
自动扫描常见安装位置（`~/ComfyUI`、`~/Desktop/ComfyUI` 等）并用 Spotlight 补搜。

- **找到**：确认是否使用
- **没找到**：三选一
  1. 手动输入本机 ComfyUI 路径
  2. 自动全新安装（克隆源码 → 创建虚拟环境 → 安装 PyTorch 与依赖，走国内镜像）
  3. 退出

### 4. 检测模型
自动识别 `models/checkpoints/` 与 `models/upscale_models/` 中的三个必需模型，缺失的逐个询问是否下载（ModelScope 镜像 + GitHub 多源回退，带进度条）。下载完成后记录 SHA-256 校验值到 `install.log`。

### 5. 安装面板
- 自动探测哪个 Python 带 PyTorch 作为后端解释器
- 内存 ≤ 24GB 自动启用 `--lowvram --cache-none` 稳定参数
- 生成 `config.json`（路径与参数配置）与 `启动闪电生图台.command`（日常启动器）

### 6. 汇总确认 → 完成
展示全部安装结果，最后询问是否立即启动。

## 三、安装产物

默认安装到 `~/Desktop/闪电生图台/`：

```
闪电生图台/
├── 启动闪电生图台.command   ← 日常启动入口（可双击）
├── config.json              ← 自动识别到的路径与参数
├── app/                     ← 面板与中转服务器
├── comfyui.log / 生图台.log  ← 运行日志
└── install.log              ← 安装/启动日志
```

## 四、启动与停止

**启动**：双击 `启动闪电生图台.command`。脚本会：
1. 检测面板是否已在运行（在运行则直接打开浏览器）
2. 后台启动 ComfyUI（8188）与面板（8190）
3. 轮询就绪后自动打开浏览器 `http://127.0.0.1:8190`

**停止**（可选）：

```bash
pkill -f 生图服务器.py && pkill -f "main.py --listen"
```

关闭终端窗口不影响后台服务；直接关浏览器即可结束使用。

## 五、卸载

1. 执行上面的停止命令
2. 删除安装目录 `~/Desktop/闪电生图台/`
3. 如不再需要 ComfyUI 与模型，另行删除对应目录

安装器不触碰 ComfyUI 本体，卸载面板不影响它。
